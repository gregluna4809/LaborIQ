# Roadmap

## Phase 1: Foundation

- Create the repository structure.
- Initialize the Spring Boot backend.
- Initialize the React, Vite, and TypeScript frontend.
- Create the Python data pipeline workspace.
- Add initial documentation and local PostgreSQL Compose configuration.

## Phase 2: Dataset Planning

- Identify public labor market datasets.
- Document source refresh cadence, licensing, and expected fields.
- Define ingestion and transformation requirements.

## Phase 3: Data Model

- Design the PostgreSQL schema for occupations, wages, skills, education, regions, and trends.
- Add migrations after the schema is reviewed.
- Add backend entities and repositories after the schema is approved.

## Phase 4: Backend APIs

- Add service and API layers for core exploration workflows.
- Add validation, error handling, and integration tests.
- Add API documentation.

## Phase 5: Frontend Experience

- Build search, filtering, comparison, and detail views.
- Add charts and workforce insight visualizations.
- Connect the frontend to backend APIs.

## Phase 6: Automation and Deployment

- Automate data refresh workflows.
- Add CI checks.
- Prepare production configuration and deployment documentation.
